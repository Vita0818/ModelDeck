# ModelDeck v0.4.2

Fixes usage accounting and the date/time filter.

- Dismiss the time-range panel with Cancel, Close, Escape, an outside click or the date trigger. Cancel discards drafts; the dashboard has one global range selector.
- Select complete calendar days, include the selected end minute, and validate empty or reversed ranges. Editing the end date no longer silently changes the start date. Live end time resolves when the range is applied.
- Count local calendar days correctly across daylight-saving transitions.
- Align processed-token totals across the overview, trends, provider statistics and model statistics, including cache reads and writes.
- Normalize fresh input using each request's stored legacy, total-input or fresh-input semantics. Show recorded cache writes when present.
- Preserve the final hourly bucket at an inclusive range endpoint, and keep zero-duration ranges from expanding to the preceding 24 hours.
- Persist auto-refresh and session-scan preferences. Display retryable loading errors, and recover log pagination when filters or result counts change.

## Downloads

The binary download is a macOS Apple Silicon (arm64) ZIP. It is ad-hoc signed, without Apple notarization. Source archives are available from this release; Windows, Linux and Intel Mac installers are not included.

## Validation

The isolated release source passed 233 frontend tests, TypeScript checking and the renderer build. Backend accounting tests and additional release checks are recorded in the attached verification file. Browser checks used synthetic records to verify totals, range endpoints, dismissal and input validation. Native window startup was checked; native automated clicking was unavailable because of a macOS capture/input error.
