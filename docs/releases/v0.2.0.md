# ModelDeck v0.2.0

2026-10-05。以 v0.1.0 为基础的客户端整合版，继续直接修改 CC Switch 源码。

## 范围

Codex CLI、Claude Code、Claude Desktop、Antigravity CLI、Cursor CLI、Cursor GUI、Grok、Muse Code、OpenCode、Hermes。

- 主切换栏直接进入所有指定客户端；适配器不再另设二级入口。
- 新客户端的未保存草稿在切换页面时保留，连接和密钥按客户端独立管理。
- 可见性设置和托盘包含新客户端。旧设置中的 MiniMax Code、OpenClaw、Pi、Gemini CLI 开关不会恢复其入口。
- 排除上述额外工具的启动导入、自动同步、目录设置和安装选项。
- 修复原生窗口在后台时等待淡入淡出动画导致页面不显示的问题。

## 兼容与验证边界

客户端协议适配器沿用已验证的 v0.1.0 实现。本次重点验证统一导航、草稿隔离、旧设置兼容、应用构建和原生界面。真实提供商调用仍需要用户的有效独立密钥；本次不把界面测试表述为真实付费模型调用验证。

数据库继续兼容 `.cc-switch`。历史数据保留，排除工具的现有配置不会由本次整合删除。运行 ModelDeck 时应退出使用同一数据目录的 CC Switch。`v0.1.0` 标签与首版发布包保留。

构建产物位于 `release/v0.2.0/`，验证记录随发布包提供。
