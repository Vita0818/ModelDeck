# ModelDeck v0.3.0

本版实现提供商与模型资源、端点路由、harness 选择之间的解耦。

## 改动

- 全局管理提供商、凭据、模型能力、上下文、输出限制与推理档位。
- 对外端点通过模型资源 ID 建立映射，可同时提供多个兼容协议。
- 十个 harness 保存端点与模型选择，共享全局资源；原生模型列表由适配器生成。
- 请求从全局资源解析实际模型和档位，目录及响应使用对外模型名。
- 自动迁移旧连接并合并同一资源，保留原配置和原生登录。
- 原生配置应用有恢复快照，写入失败会回滚，恢复会检查应用后的外部修改。
- 资源引用保护、并发版本检查及端点与 harness 兼容矩阵。

完整说明见 [两层管理](../TWO_LAYER_MODELDECK.md)。支持范围保持 v0.2.0 的十个客户端，v0.1.0 和 v0.2.0 的源码标签与安装包继续保留。

Cursor 的公开 HTTPS 地址要求、Claude Desktop 的原生模型名称要求和各协议的转换范围仍适用。原生模型菜单在修改目录后通过重新应用更新。构建与验证记录随本地发布包提供；真实上游服务的调用仍由所配置的提供商和凭据决定。
