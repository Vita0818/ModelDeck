# ModelDeck v0.1.0

Release date: 2026-10-04 (Australia/Perth).

This first version preserves the current implementation as the basis for the personal ModelDeck project. The exact pre-branding source is retained under `modeldeck-baseline-2026-10-04`.

## Included

- Existing provider and model management from CC Switch v3.20.4.
- Antigravity CLI 1.2.16 custom model connections.
- Cursor IDE 3.9.16 native BYOK configuration support.
- Cursor Agent CLI managed model catalog and native BYOK request adaptation for the verified June 12 and October 1 builds.
- Muse Code 0.1.0-R708.1 model catalog and Responses, Chat, Anthropic conversion.
- Named connection drafts, independent keys, catalog import, defaults, reasoning selection and native configuration rollback.
- Claude Desktop family ordering and gateway restoration from the current implementation.
- ModelDeck product identity, icon, bundle identifier, version and manual updates.

## Verification boundaries

The inherited client implementation was checked with 1,166 frontend tests, 3,059 Rust tests, four additional native gateway tests and two Cursor RPC probes. The ModelDeck identity changes receive their own build and targeted checks; the release verification manifest records their results.

Antigravity and Muse inference checks use real CLI programs with local mock servers. Cursor Agent checks prove its native request carries the configured model, endpoint and dedicated key; a production Cursor-to-provider response has not been verified. The Cursor IDE writer is verified against the installed native configuration schema and transaction fixtures. Runtime activation and production inference require independent credentials and the relevant account permissions.

## Compatibility

The first version retains the `.cc-switch` data contract. Use one application at a time per configuration directory. No personal credentials are distributed with ModelDeck. The application does not use the upstream CC Switch updater.
