# ModelDeck v0.4.0

This release brings the source and compilation boundary in line with ModelDeck's model-only scope.

## Retained

- Shared providers, dedicated credentials, models, context limits, capabilities, reasoning tiers and endpoint routes.
- Explicit connection application and restoration for Codex CLI, Claude Code, Claude Desktop, Antigravity CLI, Cursor CLI, Cursor GUI, Grok, Muse Code, OpenCode and Hermes.
- Provider-specific authentication, URL construction, request adaptation and streaming protocol conversion.
- Actual usage collection from Claude Code, Codex CLI, OpenCode and Grok, historical usage queries, pricing and local database archives.
- Necessary gateway, network, directory, appearance, window and logging settings.

## Removed from source and runtime

OAuth account management, WebDAV/S3 synchronization, automatic failover and circuit management, arbitrary JavaScript quota evaluation, CLI installers, auto-update management, general provider switching, native session-history relocation and unsupported client controllers. The existing exclusions for memory, MCP, Skills, prompts, session browsing and OpenClaw workspaces remain.

The application now bootstraps only its resource graph, shared HTTP gateway, native usage collectors and core desktop settings. Native connection application calls the retained leaf writers directly. The Rust library is `modeldeck_lib` and builds only an `rlib`, without redundant `staticlib` or `cdylib` outputs. Unused direct frontend and Rust dependencies have been removed.

## Compatibility

- Default data paths remain compatible with existing installations.
- Legacy database tables and records are retained for reads, migration and local SQL archives. Background backup no longer deletes historical usage or probe records.
- Saving ordinary preferences cannot activate retired account/history operations. Legacy credential fields remain passive stored data.
- Provider-link imports add graph resources; selecting a connection remains separate from applying it. Multiple upstream URLs become separate resources. Links without a model can import the upstream for later catalog setup.
- Codex official login files remain exempt during application, restoration and decoding of old native backups.
- SQL database archives remain separate from `model-deck.json`, device settings and native snapshots. Back up the full data directory for a complete configuration archive.

## Verification

The release verification record is saved alongside the packaged application. It records the remaining frontend and Rust suites, strict provider mock contracts, installed-client localhost probes, packaging checks and measured disk usage. Local mock results establish transport and ownership behavior; they do not establish production acceptance by every upstream provider or an untested client version.
