# ModelDeck v0.4.1

Adds a separate **GitHub Copilot desktop** connection alongside Copilot CLI.

- Projects shared endpoint models into the desktop app's native provider and model records, with capacity limits and the default selection for new local sessions.
- Uses the local ModelDeck endpoint token and keeps upstream credentials in ModelDeck.
- Updates and restores only the owned model records and selection. Existing providers, GitHub account data, keychain credentials and session content are preserved.
- Rolls back native model changes when application fails and stops restoration when the owned catalog has been externally edited.
- Keeps a user's later selection of another provider when restoring.
- A Responses reasoning summary by itself no longer suppresses the configured route effort. Summaries and explicit native reasoning controls are preserved.
- Supports the database schema verified in GitHub Copilot for macOS 1.0.19. Unknown schemas fail before modification. Restart the desktop app after applying.

Desktop transport validation uses the official app's bundled SDK, an isolated model database and a localhost mock upstream. The CLI and desktop entries have distinct identities and visibility settings.
