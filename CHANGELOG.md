# ModelDeck changelog

## 0.3.0 — 2026-10-05

- Separate global providers, model resources and reasoning tiers from harness selections.
- Expose endpoint model aliases through references to shared resources.
- Resolve each request from the current graph and keep upstream credentials behind the gateway.
- Generate native catalogs for all ten clients without storing separate authoritative catalogs.
- Migrate existing connections with credential-aware deduplication and preserve native login configurations.
- Add compatibility matrices, reference validation, optimistic revisions and reversible native application.
- Select compatible input protocols for OpenCode and Hermes.

## 0.2.0 — 2026-10-05

- Integrate all ten requested clients into the main client switcher.
- Keep Antigravity, Cursor CLI/GUI and Muse drafts while navigating other pages.
- Scope client visibility, tray navigation, configuration directories, tool installers and startup synchronization to the requested tools.
- Exclude MiniMax Code, OpenClaw, Pi and Gemini CLI from active product navigation and automatic synchronization.
- Preserve legacy database records and native protocol adapters for compatibility.
- Render client and settings pages immediately without waiting on hidden WebKit animations.

## 0.1.0 — 2026-10-04

- Preserve the current client model management implementation as the first ModelDeck version.
- Include Antigravity CLI, Cursor IDE, Cursor Agent CLI and Muse Code model connections.
- Introduce the ModelDeck application name, icon, bundle identifier and version.
- Register `modeldeck://` links while retaining legacy import parsing.
- Disable the inherited upstream application update channel.
- Preserve the CC Switch data format and directory for first-version compatibility.

The upstream history is preserved in Git and [the upstream changelog](docs/upstream/CHANGELOG.md).
