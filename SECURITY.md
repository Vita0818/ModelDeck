# ModelDeck security

ModelDeck's model connection code handles endpoints and independent client credentials. Keep keys out of source control, logs, error messages and exported public artifacts. Preserve client account tokens and unrelated settings when applying a model connection. Do not redirect application updates to the upstream product.

This local project has no public disclosure channel configured. Discuss security changes with the project owner using a private channel. The original upstream policy is archived at [docs/upstream/SECURITY.md](docs/upstream/SECURITY.md); its contacts belong to the upstream maintainers.
